Privacy policy

Trial & Code publisher · last updated 21 October 2026

Who this applies to

"Trial & Code publisher" is a desktop tool run only by the owner of the Trial & Code YouTube channel, on the owner's own computer, to upload that channel's own videos. It has no other users and no server.

What data the tool accesses

With the channel owner's permission (Google OAuth), the tool uses the YouTube Data API to:

  • read the basic details of the owner's own channel (name, handle) to confirm the right channel is used;
  • upload the owner's own videos, thumbnails and caption files, and set their titles, descriptions, tags and translations.

It does not read viewers' data, comments, analytics, subscribers, or any other account.

Storage and sharing

The OAuth token is stored only on the owner's computer, outside any code repository. No data is sent to any server other than Google's, and nothing is sold, shared or used for advertising.

Google and YouTube terms

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions (or security settings); the local token can be deleted from the owner's computer.

Contact

Questions: use the contact details on the Trial & Code channel page.
